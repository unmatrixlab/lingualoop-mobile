# LinguaLoop Mobile

An installable reading and listening companion for LinguaLoop 3.

## Privacy

GitHub Pages hosts only the application shell. Imported study packs and existing progress are stored locally in the browser with IndexedDB. The published repository contains no personal LinguaLoop projects or vocabulary.

## Current scope

- Two destinations: Read & listen and Studies
- Opens the current study directly; new users start in Studies to add their first study
- Complete bilingual transcripts with individual and continuous device-voice reading
- Full-video comprehension, active-subtitle following, direct seeking and subtitle clips; desktop chains do not affect phone playback
- Saved words and phrases highlighted in the English transcript using their vocabulary colors
- Compact graphite/blue translation cards with pronunciation and contextual text; dismiss to return to the same passage
- Read-only view, English/Spanish/both display and a filter for saved vocabulary
- Multiple studies, colored study rows, full-row switching and protected on-device deletion
- Learned vocabulary can be archived with confirmation, Undo and restoration from Studies
- Imports preserve reading position, vocabulary archive records and previously saved progress
- Offline reading and word lookup after installation; YouTube requires a connection and device voices depend on the phone
- Private same-Wi-Fi QR and clipboard transfer from LinguaLoop 3
- Compressed `#packz=` payload import with legacy `#pack=` compatibility

## Study pack format

LinguaLoop 3 creates a short-lived local QR route. Scanning it in the iPhone Camera opens a local handoff page in Safari. The user copies the compressed transfer, returns to the installed Home Screen app and taps **Paste study**. This explicit handoff is required because iOS keeps Safari storage separate from an installed Home Screen web app. GitHub Pages never receives the vocabulary; the transfer stays between the computer, clipboard and installed app.

Direct `#packz=` URL import remains supported for browsers and platforms that keep the web app in the same storage context.

Sending an updated study replaces its content while preserving the review progress and playback position already stored on this phone. Reading position and word archive remain local to this phone; progress does not sync back to the computer. Optional `colorIndex` preserves an explicitly chosen desktop vocabulary color. Older packs remain compatible and receive stable default colors.

The decoded study pack uses this structure:

```json
{
  "version": 4,
  "studies": [{
    "id": "stable-project-id",
    "name": "Study name",
    "color": "#76a8ff",
    "media": {
      "type": "youtube",
      "id": "YouTube-video-id",
      "name": "Source video title"
    },
    "transcript": [{
      "id": "subtitle-1",
      "start": 42.2,
      "end": 45.1,
      "en": "Complete English subtitle.",
      "es": "Subtítulo completo en español.",
      "chain": 0
    }],
    "cards": [{
      "id": "stable-card-id",
      "english": "Target phrase",
      "spanish": "Translation",
      "context": "Optional context",
      "colorIndex": 4,
      "clip": { "start": 42.2, "end": 47.8 },
      "level": 0,
      "dueAt": 0,
      "reviews": 0,
      "correct": 0
    }]
  }]
}
```

## Reading and recovery

Read & listen keeps its video and navigation controls fixed while the transcript scrolls. Tap a highlighted word for its translation, source sentence and pronunciation in a compact card. Close it with ×, Escape or a tap on the dimmed background. The reader stays at the same passage.

Studies manages imported projects and learned vocabulary. Add study remains accessible there. Marking a word as learned archives it on this phone, removes its transcript highlighting and leaves the desktop vocabulary untouched. Undo or Studies → Learned → Restore brings it back. Reimports preserve archive records even when a word is temporarily absent from the incoming pack.

Practice screens and exercise actions have been removed. Previously stored review history and session data are retained in the local library, with no new reviews generated by opening a translation.

Device speech is initiated by a tap. Voices depend on the phone. No remote AI or analytics service is required. YouTube remains online-only.
